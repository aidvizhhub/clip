# clip

Сниппеты в буфер обмена одной кнопкой. Кидаешь файлы в `~/clip` — хоткей кладёт содержимое в буфер.

## Установка

```bash
bash install.sh
```

Ставит:
- `~/.local/bin/clip`
- ярлыки «clip — буфер» и «clip — всё в буфер» в меню приложений
- хоткеи GNOME: `Ctrl+Alt+C` (выбрать) и `Ctrl+Alt+A` (всё разом)

Зависимости: Wayland — `wl-clipboard`, X11 — `xclip`; меню — `zenity`; уведомления — `notify-send`.

## Использование

Кидаешь в `~/clip` любые текстовые файлы. Дальше:

- `Ctrl+Alt+C` — меню: выбираешь файл, его содержимое в буфере. Первый пункт «★ всё содержимое (Ctrl+Alt+A)» — склеить все файлы.
- `Ctrl+Alt+A` — сразу склеить всю папку в буфер (по алфавиту, через перенос строки).
- Если в папке один файл — он копируется без меню.

Из командной строки:

```bash
clip              # выбрать файл из меню и скопировать
clip all          # склеить все файлы папки в буфер
clip last         # самый свежий файл без меню
clip 2            # файл №2 из списка (свежие сверху)
clip имя.txt      # конкретный файл по имени
clip save [имя]   # сохранить содержимое буфера в новый файл (clip-ДАТА.txt)
```

Папка меняется через `CLIP_DIR`:

```bash
CLIP_DIR=~/сниппеты clip last
```

## Удаление

```bash
rm ~/.local/bin/clip ~/.local/share/applications/clip*.desktop
# хоткеи: Настройки → Клавиатура → Свои комбинации
```
