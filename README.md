# clip

Сниппеты в буфер обмена одной кнопкой. Кидаешь файлы и папки в `~/clip` — хоткей кладёт содержимое в буфер.

## Установка

```bash
bash install.sh
```

Ставит:
- `~/.local/bin/clip`
- ярлыки «clip — буфер» и «clip — всё в буфер» в меню приложений
- хоткеи GNOME: `Ctrl+Alt+C` (выбрать) и `Ctrl+Alt+A` (всё разом)

Зависимости: Wayland — `wl-clipboard`, X11 — `xclip`; меню — `zenity`; уведомления — `notify-send`.

## Использование

Кидаешь в `~/clip` любые текстовые файлы. Хочешь порядок — раскладывай по папкам: папка в меню помечена `/` на конце, выбор папки клеит в буфер всё её содержимое (рекурсивно, по алфавиту, файлы через перенос строки).

Где лежит папка сниппетов — написано в шапке меню: «откуда: ~/clip». Подпапки делаешь там же:

```bash
mkdir ~/clip/python ~/clip/prompts
```

Хоткеи:

- `Ctrl+Alt+C` — меню: файлы и папки. Первый пункт «★ всё содержимое (Ctrl+Alt+A)» — склеить всё.
- `Ctrl+Alt+A` — сразу склеить всё содержимое `~/clip`, включая подпапки.
- Если в папке один элемент — он копируется без меню.

Из командной строки:

```bash
clip              # меню: файлы и папки из ~/clip
clip all          # склеить всё, включая подпапки
clip sub          # склеить папку sub целиком
clip last         # самый свежий файл без меню
clip 2            # элемент №2 из меню (папки, потом файлы)
clip имя.txt      # конкретный файл по имени
clip save [имя]   # сохранить содержимое буфера в новый файл (clip-ДАТА.txt)
```

Папка меняется через `CLIP_DIR`:

```bash
CLIP_DIR=~/сниппеты clip last
```

## Удаление

```bash
rm ~/.local/bin/clip ~/.local/share/applications/clip*.desktop
# хоткеи: Настройки → Клавиатура → Свои комбинации
```
